## 5. 原型定义

| 原型 | 生成特征 |
|---|---|
| 高财富、高分享 | 利润率较高，员工投入、福利和共同增长指标也较高 |
| 高财富、低分享 | 利润率较高，劳动投入强度和基层收入增长偏低 |
| 高分享型 | 员工分配和福利投入较高，企业利润不要求处于高位 |
| 低财富、高善待 | 利润率一般或偏低，但基层收入和福利相对较好 |
| 高薪、高工时 | 人均投入和中位收入较高，平均及P90工时也较高 |
| 低薪、低工时 | 收入充足度偏低，但工时和安全表现相对正常 |
| 低薪、高工时 | 收入充足度偏低，工时长且离职率较高 |
| 低薪、高流动 | 基层收入较低，员工离职率较高 |
| 高管差距型 | 最高薪高管与人均劳动投入差距较大 |
| 股东优先型 | 分红和回购增长快于员工现金投入 |
| 共同成长型 | 人均营收与员工人均投入同步增长 |
| 外包规避型 | 正式员工指标尚可，但外包比例高且待遇差距明显 |
| 数据透明型 | 数据完整度高，但不因此自动获得高表现分 |
| 数据不透明型 | 多个员工福利字段主动缺失，可能不具备排名资格 |
| 持续改善型 | 三年内收入、福利、工时或分配指标持续改善 |
| 快速扩张型 | 营收和人员快速增长，现金流和人员稳定性可能波动 |
| 就业稳定型 | 员工人数、工时和离职率相对稳定 |
| 高工时型 | 工时明显偏高，但收入不一定高 |

## 6. 分布检查

生成数据前必须确认：

- 三个行业各10家；
- 至少4家高数据完整度企业/行业；
- 至少2家低数据完整度企业/行业；
- 至少5家改善型企业；
- 至少4家恶化型企业；
- 至少4家外包相关企业；
- 至少3家高管差距企业；
- 至少3家股东优先企业；
- 至少3家低财富、高善待企业；
- 不允许所有“高财富”企业都排在前列；
- 不允许所有小型企业都排在后列。

## 7. 命名与对外展示规则

1. 所有名称均为虚构名称。
2. 不使用真实企业简称、商标或宣传口号。
3. 不公开任何真实企业到合成企业的映射。
4. 企业卡片固定显示“模拟企业”。
5. 企业详情页固定显示“演示数据，不对应真实企业”。
6. 对外分享图片必须携带“模拟数据”水印。
