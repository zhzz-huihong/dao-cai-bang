# 道财榜

> 不只看企业创造了多少财富，也看财富如何抵达普通劳动者。

道财榜是一个面向公众的企业财富分享与员工福祉评价产品。它尝试把企业经营能力、基层员工收入、福利保障、工时安全、内部分配差距和责任治理放进同一套可解释的评价框架中，为公众提供一种不同于传统财富榜的观察视角。

当前仓库为 **“道财榜·模拟数据演示版”**，用于验证产品概念、数据结构、评分方法和交互体验。全部企业名称及员工福利数据均为虚构或合成内容，不对应任何真实企业，也不构成企业评级、投资建议或求职建议。

## 为什么做道财榜

传统财富榜通常回答“谁拥有更多财富”，却较少回答：

- 企业成长后，基层员工是否同步受益？
- 最低收入员工能否获得足以维持体面生活的报酬？
- 企业利润增长是否建立在超长工时或安全风险之上？
- 高管、股东与普通劳动者之间的分配是否失衡？
- 外包、派遣劳动者是否被排除在企业福利之外？

道财榜希望让“企业如何对待创造财富的人”成为公众能够看见、比较和讨论的信息。

## 产品如何评价企业

道财指数满分为 100 分：

```text
道财指数
= 财富创造质量（25分）
+ 员工福祉与财富分享（60分）
+ 责任治理（15分）
- 红线扣分
```

| 一级维度 | 权重 | 关注内容 |
|---|---:|---|
| 财富创造质量 | 25% | 人均营收、净利润率、经营现金流率、就业稳定性 |
| 员工福祉与财富分享 | 60% | 基层收入、劳动分配、收入差距、福利、工时、安全与职业发展 |
| 责任治理 | 15% | 外包劳动者责任、员工参与和数据透明度 |

评分不按营业收入、员工人数或企业绝对规模直接加分。能够创造财富是基础，是否公平、可持续地分享财富才是榜单的核心。

为避免“没有披露就等于没有问题”，缺失数据不会直接记为零，但会降低数据完整度和透明度得分；完整度低于 70% 的企业进入观察组，不参与排名。重大死亡事故等红线事件会独立扣分，不能被其他高分完全抵消。

完整方法见[《道财榜评分方法 V1.0》](docs/评分方法_V1.0.md)。

## 当前演示版

现有 MVP 包含：

- 30 家合成企业；
- 制造、科技、零售物流服务 3 个行业；
- 2023—2025 年三年模拟数据；
- 综合榜与行业筛选；
- 企业搜索和经营类型筛选；
- 企业详情及三年趋势；
- 最多 3 家企业横向比较；
- 数据完整度、排名资格及观察组展示；
- 明确、持续可见的模拟数据标识。

## 浏览产品原型

进入站点目录并启动本地静态服务器：

```powershell
cd .\site
python -m http.server 4173 --directory dist
```

随后访问：

```text
http://127.0.0.1:4173/
```

原型采用原生 HTML、CSS 和 JavaScript 构建，不需要安装前端依赖。

## 数据说明

当前数据采取“公开数据结构参考 + 合成企业 + 模拟缺失”的方式构造：

- 财务结构参考现实行业的合理区间，但不复制某一家真实企业；
- 企业名称、员工收入、福利、工时和安全数据均为合成内容；
- 部分字段被主动设置为缺失，用于验证透明度和观察组机制；
- 每项数据保留来源类型和证据状态，方便未来迁移到真实公开数据；
- 所有评分均可通过脚本重新计算。

因此，本版本只能用于演示“如果数据存在，榜单可以怎样工作”，不能用于判断任何真实企业是否善待员工。

## 从演示版走向公众榜单

下一阶段重点不是扩大模拟企业数量，而是验证方法并建立可信的数据基础：

1. 邀请普通员工、研究者和媒体完成首轮体验测试；
2. 检查指标是否易懂、权重是否合理、行业差异是否公平；
3. 建立真实公开数据采集表和证据分级规则；
4. 选择少量企业进行可复核的数据试采集；
5. 建立企业更正、申诉和版本留痕机制；
6. 经外部方法审议后，再考虑发布真实企业测试榜单。

## 产品原则

- **公共价值优先**：关注普通劳动者是否分享企业发展成果。
- **方法透明**：公开指标、权重、缺失处理和扣分规则。
- **证据可追溯**：结论必须能够回到数据来源和计算过程。
- **区分事实与模拟**：不把合成数据包装成真实调查结果。
- **允许纠错**：未来真实榜单必须提供更正、申诉和版本记录。
- **谨慎排名**：当数据质量不足时，宁可进入观察组，也不制造虚假的精确性。
